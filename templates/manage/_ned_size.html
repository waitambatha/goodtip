{% comment %} Font size control for a story-editor toolbar. Pass `default` — the size in px that this surface already renders at, so the box starts by telling the truth rather than saying "Size". This replaced a dropdown of Small / Medium / Large / XL. Those names were a guess dressed up as a choice: they gave no idea what size you were about to get, no idea what size you were already on, and no way to ask for anything in between. A number you can nudge up and down does all three. {% endcomment %}
