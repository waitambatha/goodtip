{% comment %} Font size control for a story-editor toolbar. Pass `default` — the size in px that this surface already renders at, so the box starts by telling the truth rather than saying "Size". This replaced a dropdown of Small / Medium / Large / XL. Those names were a guess dressed up as a choice: they gave no idea what size you were about to get, no idea what size you were already on, and no way to ask for anything in between. A number you can nudge up and down does all three. Nudging alone turned out not to be enough. Going 16 → 48 is thirty-two clicks, and nothing tells you which sizes are worth choosing. So the number is a button too: click it and the usual sizes drop down in a list to scroll and pick from, while − and + stay for the one-point adjustments and the box stays typeable for anything not on the list. gt-news-editor.js fills the list in. {% endcomment %}
