It used to be frozen, on the reasoning that a link already sent to somebody must keep working — which was right about the risk and wrong about the fix. So it moves, and the old address is written into the redirect table pointing here (`admin_panel.views._apply_news_slug`). {% comment %} PUBLISH DATE — BACKDATING AND SCHEDULING IN ONE FIELD. It was set to "now" at creation and never shown, so a write-up of last weekend's games was dated today and sorted above this weekend's. A date in the past puts the story where it belongs; a date in the future holds it back until then, with no cron and nobody having to be at a keyboard — every reader-facing query asks for `published_at <= now`, so the moment simply arrives. See admin_panel.models.LivePostManager. `datetime-local` sends wall-clock time with no zone; the view reads it in the site's timezone, so "Friday 9am" means 9am here. {% endcomment %}
