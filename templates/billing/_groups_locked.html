{% comment %} THE UPGRADE PROMPT FOR GROUPS. Drawn wherever a group control is disabled, immediately beside the control it explains. The client's instruction was specific about the shape of this: "a visible but disabled/greyed group-creation entry point, with a click triggering the upgrade prompt ... rather than removing the menu item entirely" — and "don't just hide the option, they should see what they're missing and get a clear upgrade path". So it names three things and no more: what groups would give them, which plan carries it and what that costs, and one button to go and get it. The reasoning ("one shared ladder keeps a comp this size lively") is the client's own, and it is there because a gate that reads as a paywall alone invites the reply "so you've taken a feature away"; a gate that says why the line is drawn where it is does not. Context comes from billing.entitlements.groups_context: `groups_gate`, `groups_locked_blurb` and `groups_upgrade_url`. Include it inside the block that holds the disabled control, never as a standalone banner at the top of a page — a prompt that has floated away from the thing it is about is just an advertisement. {% endcomment %}
