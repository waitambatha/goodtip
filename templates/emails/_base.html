FULL-BLEED PHOTOGRAPH, AND A MESSAGE SHORT ENOUGH TO CARRY IT The picture runs the whole height with the card floating on it. That only works if the email FITS: background-size:cover stretched across a message two thousand pixels tall blows the crop up until the photo reads as a smear, and the reader is scrolling past it either way. So the thing that makes this design work is vertical restraint — every padding below is the smallest value that still breathes, so a sign-in code lands inside one laptop screen and the photograph stays a photograph. If a message ever needs more content than fits, it belongs behind a link. THE PHOTOGRAPH IS DECORATION, NEVER STRUCTURE Outlook desktop blocks remote images by default, so the photo is layered OVER a solid #0B1F17 that carries the same weight: images off, this is still the dark-green branded message, just without the crowd. Nothing meaningful lives in an image — no text, no code, no button.
