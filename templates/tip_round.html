{% comment %} BUTTONS, NOT RADIOS (Aug 2026). These were two labels over a hidden radio group, each radio posting itself on `change`. That shape cannot express "no tip": a radio group has no way back to none, and pressing the side you had already chosen fires no change event at all, so the second press did nothing — which is exactly what the client reported. Buttons have no such state to get stuck in. Each button posts the side it names, or "none" when it IS the current pick, so the same control picks and un-picks. Same contract as the My Tips card (partials/_fixture_team.html), which is the other place a tip saves the instant it is made. {% endcomment %}
