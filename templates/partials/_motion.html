{% comment %} Motion is part of GoodTip's design, so it plays for every visitor (client, 5 Oct 2026) — including people whose computer asks sites for "reduced motion", which many machines do by default or after a battery/animation setting change. Those visitors used to get a static site with nothing typing or turning, and it looked broken. This runs first in every , before any stylesheet or script: * html.gt-motion goes on — every reduced-motion CSS rule is scoped to html:not(.gt-motion), so none of them apply; * window.matchMedia answers "(prefers-reduced-motion: …)" as if the visitor had no preference, so every script — ours and inline — animates. `?motion=0` is the way out for anyone who needs still pages: it is remembered, and the computer's own setting is honoured again. `?motion=1` undoes it. {% endcomment %}
