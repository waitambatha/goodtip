{% comment %} ============================================================================= EIGHT LOADER SCENES — FOUR FOR THE AFL, FOUR FOR THE NRL. ============================================================================= CLIENT, 20 SEP 2026: "let's only have NRL and AFL, so that means think so that they will be like 8 loaders. For the NRLW, either male or female, on their loader we can add the sign of male or female." WHY THE OTHER TWO WENT. The rotation used to carry six, one per Series in the database — which put Super Netball in it, and a round ball dropping through a ring reads as basketball long before it reads as netball. Checking the data settled it rather than taste: Super Netball and Super League have ZERO rounds and ZERO matches. Nobody tips them. A splash was advertising a competition the product does not run, in a sport it does not cover. State of Origin went with them — it has fixtures, but it is three games a year inside the NRL, and the same client asked a week ago that it stop being treated as a competition in its own right on the landing screens. TWO CODES, FOUR SCENES EACH, AND THE SEX MARK CARRIES THE REST. Four competitions still need telling apart, and the answer is not eight more drawings: an AFLW set shot and an AFL set shot are the same act. So the CODE picks the scene and the colour, and a ♀ / ♂ mark in the corner says which side of it — which is both less work and more honest, because it is exactly how the competitions relate to each other. AFL set shot · centre bounce · the mark · the goal umpire NRL conversion · tackle count · the try · the pass Eight scenes, eight different motions: arc, bounce, catch, wave, arc-over, count, place, chain. No two of them can be mistaken for one another, which was the whole complaint about the first attempt. COLOUR IS NEVER SPELLED OUT HERE. Every scene draws in --lc, which gt-loader.js points at the [data-code] token block in goodtip.css — so the AFLW scenes come up rose and the NRLW ones orchid without a single rule here knowing that. `lanim` on every moving part is not decoration: it is what exempts these from the blanket reduced-motion rule in goodtip.css. Without it they are frozen, and a frozen loader says the opposite of what a loader is for. ============================================================================= {% endcomment %}
{% comment %} THE SEX MARK, drawn once and switched by [data-sex] on #loader rather than copied into all eight scenes. One copy is one thing to redraw; eight is seven chances for them to drift apart. Bottom-right, small, in the competition's own colour: it is a qualifier on the scene, not the subject of it. Both marks are drawn — the men's as well as the women's — because a mark that appears only on the women's scenes reads as the women's competition being the variant and the men's being the default, which is not how these two sit in the product. {% endcomment %} {# ==================== AFL ==================== #} {# ---- 1. THE SET SHOT (arc) ---- #} {% comment %} Four posts: the tall goal pair, the short behind pair outside them. The silhouette is the whole tell — an AFL set of posts must never be drawn as an H, per the client's own Goal Posts Reference. The two flags going up after it are what make the loop a GOAL rather than a ball leaving the frame. {% endcomment %}
{# ---- 2. THE CENTRE BOUNCE (bounce) ---- #} {% comment %} The centre square and circle from above, ball driven into it and coming back up. The one moment in Aussie Rules that looks nothing like anything in rugby league, and the only scene where the ball comes back towards the viewer. {% endcomment %}
{# ---- 3. THE MARK (catch) ---- #} {% comment %} The ball drops out of the sky and two arms come up and take it. The only scene of the eight where something REACHES for the ball rather than sending it somewhere, and the one act that is most associated with this code. {% endcomment %}
{# ---- 4. THE GOAL UMPIRE (wave) ---- #} {% comment %} Two flags waved from the boundary and six points going up on the board. No ball in the scene at all: this is what happens AFTER one, and it is the only motion of the eight that is a person signalling rather than a ball moving. {% endcomment %}
{# ==================== NRL ==================== #} {# ---- 5. THE CONVERSION (arc over) ---- #} {% comment %} The H. Uprights that carry on above the crossbar, which is the difference a rugby league supporter reads in a quarter of a second — and the ball clears a BAR here rather than threading a gap, which is what separates this from the AFL set shot beyond the colour. {% endcomment %}
{# ---- 6. THE TACKLE COUNT (count) ---- #} {% comment %} Five tallies lighting one at a time, the sixth stroke drawn through them, and the ball played back as the set restarts. Nothing flies anywhere: this scene COUNTS, which is a rhythm rather than a trajectory, and it is the only one of the eight whose timing a supporter can predict before it happens. {% endcomment %}
{# ---- 7. THE TRY (place) ---- #} {% comment %} The try line and the in-goal beyond it. The ball comes in low, is grounded, and STAYS there while the line lights and a ring goes out from the spot. The only scene that ends with the ball at rest — a try is a ball being put somewhere, which is the other half of how rugby league is scored. {% endcomment %}
{# ---- 8. THE PASS (chain) ---- #} {% comment %} Three players and the ball going down the line, each one lighting as it reaches them. The one scene built out of a SEQUENCE across the width rather than a single flight — closest in spirit to the tackle count, and separated from it by having something actually travel. {% endcomment %}
